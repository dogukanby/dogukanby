### A few things I've built

**[CloudLab](https://github.com/dogukanby/cloud-systems-console)** — an interactive, browser-based simulation of core cloud architecture concepts: IAM, VPC, EC2, S3, Lambda, load balancing, CI/CD, distributed consistency, and more. Every module pairs a plain-language explanation with a hands-on simulation and a real production incident (HealthCare.gov, Uber, GitHub, Capital One...) it maps to, plus scenario-based "quests" grounded in real AWS certification exam questions.

**[ScrAutoClicker](https://github.com/dogukanby/scrautoclicker)** — a Windows autoclicker with a full desktop GUI that finds things on screen three ways: a reference image (OpenCV), exact text (OCR), or a plain-English description read by Claude's vision model. Supports sequential "runs" with looping, packaged as a single exe.

**[expo-firebase-auth-persistence](https://github.com/dogukanby/expo-firebase-auth-persistence)** — a fix for a specific, annoying bug: silent auth logouts on app restart when using Firebase Auth with Expo / React Native.
